Segue

What happens by default when a link is sent to another window. The menu's second entry, and switch to it, overrides both of these for a single click, and Alt+Shift-click inverts them.

Where the link lands

The tab becomes the active one in the target window, but that window is not raised. Off, it opens behind the tabs already there.

Off, the link waits for you in the other window — which is usually the point of sending it there rather than opening it here.

Alt-click

Name a window with the toolbar button, then set it as the target there or type the name here. If no window carries the name, one is created and given it — so this keeps working after a restart, when every window id has changed. Left empty, Alt-click just opens a new window.

A link clicked in Word or Outlook lands in whichever Edge window was focused last — nothing chooses it. With this on, such a tab is moved to the window named above and brought to the front. It is recognised by being active, having no opener and already carrying a real address; a bookmark opened straight into the foreground can look the same and would be moved too.

Window title

Appends [Name] to the title of every tab in a named window, which is what the title bar and the taskbar show. This is the only way a name set here reaches anything outside the browser — with it on, a script can find the window by that name. At the end rather than the front so that a narrow or vertical tab list truncates the name away instead of the page title. Pages where extensions cannot run (edge://, the new tab page, PDFs) keep their own title.

Puts the address in the title as well, before the name, so that the name — the part you match on — is the last to be truncated. Needs the switch above. Turn off any other extension that writes the address into the title: two of them append to the same string without knowing about each other, and the title grows a copy at a time.
